    Hands on Labs - CDF

    Welcome to the Cloudera DataFlow Hands-on Labs! These labs will equip you with practical skills for building, testing, and deploying real-time data pipelines on Cloudera Data Platform.

    You will learn how to design and deploy NiFi flows with the CDF Flow Designer, manage schemas with Schema Registry, stream data into Apache Kafka, run real-time analytics with SQL Stream Builder (Flink), persist results in Apache Kudu, and capture database changes end-to-end using Kafka Connect with Debezium CDC.
